# Changelog

## 0.1.0

First public version of Scrifts, a free font editor for Windows built on FontForge.

- Opens and saves .glyphs, .ufo, .otf, .ttf, .sfd; masters, snapshots, undo and redo
- Drawing: pen, shapes, Selection and Direct Selection, Shaper, live rounded corners (adjust or sharpen them later), strokes
- Spacing and kerning with groups, auto-space and auto-kern; right-to-left and joining scripts
- Features page (ligatures, small capitals, stylistic sets), language systems for any script
- Trace a picture into a glyph, printable template sheets, SVG round trip with Illustrator
- Plugins, Script view, command palette (Ctrl K), proof sheet through the print dialog
- A variable font can be split into editable masters (Axes panel, Edit as masters): a project folder with one .sfd per axis end and a .designspace
- New fonts get their own folder, named after the family, so masters stay together
